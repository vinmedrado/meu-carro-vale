# Roteiro de demonstração — Meu Carro Vale

## Objetivo

Mostrar em poucos minutos que o Meu Carro Vale não é apenas uma calculadora de preço, mas uma plataforma de negociação automotiva com visual profissional, inteligência de mercado e laudo pronto para apresentação.

## Fluxo recomendado

1. **Landing** — apresentar a dor: vender abaixo do valor por falta de referência.
2. **Entrada demo** — clicar em “Ver demonstração” ou “Avaliar meu veículo”.
3. **Painel** — mostrar o veículo pré-preenchido e os cards executivos.
4. **Modo demo rápido** — alternar entre Corolla, BMW, Civic e Compass.
5. **Laudo** — destacar Índice Meu Carro Vale™, Valor de Mercado™ e Potencial Perdido™.
6. **PDF** — clicar em exportar laudo.
7. **Anúncio** — abrir gerador de anúncio e copiar uma versão.
8. **Fechamento** — explicar roadmap para FIPE real, anúncios reais e visão computacional.

## Frase curta para vídeo

“O Meu Carro Vale ajuda o vendedor a entender quanto o veículo realmente vale, visualizar o potencial financeiro perdido e sair com um laudo profissional para negociar melhor.”

## Pontos fortes para destacar

- Experiência visual profissional.
- Dados demo prontos para showcase.
- Backend FastAPI preservado.
- Exportação PDF real.
- Produto com potencial comercial claro.
- Stack moderna e organizada para portfólio.
